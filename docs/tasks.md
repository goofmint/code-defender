# タスク一覧：Code Defender

企画書 [game_plan.md](game_plan.md) をもとにした開発タスクです。企画書で「未定」「案」「叩き台」「ドラフト」となっている内容は、決めるタスクとして分けています。

## 0. 仕様を決めるタスク
- [x] X上での具体的な動かし方を決める（Webページとして作り、Player Cardのメタタグも付ける）
- [x] エンジニアの性格の種類を決める（几帳面、消極的、適当、サボりがち、真面目、冷静沈着、陽気、根暗）
- [x] パラメータを決める（疲労度・集中力・技術力・愛着心）
- [x] 性格ごとのパラメータの傾向を決める（3段階、game_plan.md参照）
- [ ] 性格ごとのパラメータの具体的な数値を試作で調整する
- [x] 疲労度・集中力・技術力の効果を確定する
- [ ] 給料が愛着心に与える影響の詳細を決める
- [x] 疲労度の仕組みを入れるかどうか決める（入れる）
- [ ] 技術的負債の具体的な計算方法を決める
- [ ] 各ランクの不正コード率（開始時・上限）を確定する
- [ ] 給料、売上、損害額などの各種数値を決める
- [ ] 支払い（給料）が発生する「一定期間」の長さを決める
- [ ] 採用するアイテムと、各アイテムの役割・効果を確定する
- [ ] アイテムの価格（ステージポイント・リリースで稼いだポイント）を決める

## 1. 開発環境
- [ ] Vite＋TypeScriptのプロジェクトを作る
- [ ] Phaserを導入する
- [ ] 開発サーバーで空の画面が表示されることを確認する

## 2. フィールドとルート
- [ ] 2Dフィールドを表示する
- [ ] リリース地点を配置する
- [ ] エンジニアごとの出現場所からリリース地点までの決まったルートを作る
- [ ] エンジニアが増えたときに出現場所とルートを追加できるようにする

## 3. 主人公
- [ ] 主人公（エンジニア）を表示する
- [ ] 主人公がフィールドを自由に動き回れるようにする
- [ ] 主人公がコードを攻撃できるようにする

## 4. コード
- [ ] 正常なコードと不正なコードを、色や形で見分けられる見た目で作る
- [ ] コードが出現場所からルートに沿ってリリース地点へ流れるようにする
- [ ] エンジニアのランクに応じた割合で不正なコードを出す
- [ ] 不正なコードの割合を可変にする
- [ ] 時間とともにコードの流れを速くし、不正なコードを増やす

## 5. 判定とお金
- [ ] 不正なコードを倒せるようにする
- [ ] 正常なコードを攻撃したら減点する
- [ ] 正常なコードがリリースされたら売上として加算する
- [ ] 不正なコードがリリースされたら障害を起こし、損害として資金を減らす
- [ ] 一定期間ごとにエンジニアの給料を引く
- [ ] 資金がなくなったら倒産でゲームオーバーにする
- [ ] スコアとして倒産までの累計売上を表示する

## 6. エンジニアの雇用
- [ ] ジュニア・ミドル・シニアの3ランクから雇えるようにする
- [ ] ランクごとに不正コードの割合を変える
- [ ] ランクごとに給料を変える
- [ ] 雇ったときに性格がランダムで付くようにする
- [ ] 雇うと出現場所とルートが増えるようにする
- [ ] エンジニアごとに疲労度・集中力・技術力・愛着心のパラメータを持たせる
- [ ] 性格ごとにパラメータの値を変える
- [ ] 休暇で愛着心が上がり、疲労度が高いまま働かせると下がるようにする
- [ ] 給料が愛着心に影響するようにする
- [ ] 愛着心が最低になったら自主退職し、そのルートが消えるようにする
- [ ] 給料の初期額をランクで決める
- [ ] プレイヤーがいつでも昇給・減給できるようにする

## 7. 休暇
- [ ] 好きなタイミングでエンジニアに休暇を与えられるようにする
- [ ] 休暇中はそのエンジニアのコードを止める
- [ ] 休暇中も給料を引く
- [ ] 休暇を取らせること自体ではポイントが増減しないようにする
- [ ] 休暇を与えると不正コード率が下がるようにする

## 8. 機能開発とリファクタリング
- [ ] 機能開発とリファクタリングの割合を指定できるUIを作る
- [ ] リファクタリングを強化すると品質が良くなる（不正コードが減る）ようにする
- [ ] 機能開発を強化すると売上に繋がるようにする
- [ ] 技術的負債の仕組みを入れる（機能開発に偏ると後で障害が増える）

## 9. アイテム
- [ ] ステージポイントによる初期配置の画面を作る
- [ ] リリースで稼いだポイントでプレイ中にアイテムを追加できるようにする
- [ ] アイテムが正常なコードを攻撃しないようにする
- [ ] CodeRabbitを実装する
- [ ] AIコーディングエージェント（強い・普通・安い）を実装する
- [ ] テストツールを実装する
- [ ] CIを実装する
- [ ] 採用が決まった追加アイテムを実装する

## 10. UI
- [ ] 資金・累計売上を常に表示する
- [ ] ゲームオーバー画面でスコアを表示する

## 11. X対応
- [ ] Player Card用のメタタグ（`twitter:card`、`twitter:player`、`twitter:image`など）を付ける
- [ ] Player Cardのiframe枠に収まるレスポンシブな画面にする
- [ ] ポスト内で動くか実際に試す
