# 企画書（ドラフト）：エンジニア × コードディフェンスゲーム

> 未確定の項目は「未定」と記載しています。

## 1. 概要
- Webブラウザで動く2Dディフェンスゲーム
- Xのポストから遊べるもの（X上での具体的な動かし方は未定）
- 主人公はエンジニア
- 正常なコードの中に時々紛れ込む不正なコードを退治し、正常なコードだけをリリースする

## 2. ゲームの目的とスコア
- 高得点を競うスコアアタック形式（ステージ制ではない）
- スコアは **倒産までの累計売上**
- ゲームオーバー条件は **倒産**

## 3. 基本ルール
- 不正なコードは、色や形が正常なコードと違う（見た目で見分ける）
- 正常なコードを攻撃すると減点
- 正常なコードだけをリリースすることでポイントを稼ぐ
- 不正なコードがリリースされると障害につながり、障害は損害（資金の減少）につながる

## 4. フィールドと移動
- 2Dのフィールド
- 主人公はフィールドを自由に動き回れる
- コードは決まったルートを通ってリリース地点へ向かう
- コードの出現場所は、雇っているエンジニアの数だけある

## 5. 難易度
- 時間とともにコードの流れが速くなり、不正なコードも増える

## 6. エンジニアの雇用
- ジュニア・ミドル・シニアの3ランクから雇える
- ランクによって、出てくる不正なコードと正常なコードの割合が変わる
- ランクによって、一定期間ごとの支払い（給料）が変わる
- 性格はランダムで付く（選ぶのに時間がかからないようにする）
  - 性格ごとの効果：未定

### 不正なコードの割合
- 不正なコードがそれなりに来ないとゲームとして面白くないため、一定以上の割合を確保する
- 割合は固定ではなく可変
- 数値は叩き台（試作しながら調整する）

| ランク | 開始時の不正コード率（叩き台） | 時間が経った後の上限（叩き台） |
|---|---|---|
| ジュニア | 40% | 60% |
| ミドル | 25% | 45% |
| シニア | 10% | 25% |

### 休暇
- プレイヤーは好きなタイミングでエンジニアに休暇を与えられる
- 休暇を与えると、そのエンジニアの不正コード率が下がる
- 休暇を取らせること自体にポイントの増減はない
- 休暇中も給与は引かれる
- 休暇中はそのエンジニアのコードは出ない（その分の売上は入らない）
- 疲労度の仕組み（働くほど不正コード率が上がり、休暇でリセット）：案

## 7. 機能開発とリファクタリング
- プレイヤーが機能開発とリファクタリングの割合を指定できる
- リファクタリングを強化するとプロダクトの品質は良くなるが、機能開発が進まないため売上には繋がらない
- 機能開発を強化すると売上に繋がる
- 技術的負債の仕組みを入れる（機能開発に偏ると後で障害が増える）
  - 具体的な計算方法：未定

## 8. アイテム
### 入手方法
- ステージポイントによる初期配置
- リリースで稼いだポイントでプレイ中に追加
- 正常なコードは攻撃しない

### アイテム案（ドラフト・今後さらに増やす予定）
| アイテム | 役割（案） |
|---|---|
| CodeRabbit | ルート上に置くと、射程内の不正なコードを見つけて倒す |
| AIコーディングエージェント（強い・普通・安い） | エンジニアに付けて、コードの出力ペースを上げる。安いほど不正なコードを混ぜやすい |
| テストツール | ルート上で不正なコードを足止めする |
| CI | リリース地点の直前で、すり抜けた不正なコードを一定確率で止める。通るコードが少し遅くなる |

### 追加アイテム候補（ドラフト）
| 分類 | アイテム | 効果（案） |
|---|---|---|
| 攻撃・防御 | 静的解析ツール（Linter） | 射程は短いが連射が速い。怪しい見た目の正常コードに反応しかけて、ときどき止まる |
| 攻撃・防御 | ペアプロ相棒 | 主人公についてまわり、一緒に不正コードを叩く |
| 攻撃・防御 | セキュリティスキャナー | 特に危ない「脆弱性コード」に大ダメージ |
| 攻撃・防御 | ラバーダック | 近くの不正コードの正体がバレて、色が濃く見える |
| 足止め・妨害 | コードフリーズ | 一定時間、全ルートの流れを止める。その間は売上も止まる |
| 足止め・妨害 | 長すぎる会議 | 不正コードを足止めする。たまに正常コードも巻き込む |
| 足止め・妨害 | 仕様変更の嵐 | ルート上のコードがぐるぐる回り、出現ペースがリセットされる |
| 経済・稼ぎ | コーヒーマシン | 近くのエンジニアの出力ペースが上がる。置きすぎるとカフェイン切れで下がる |
| 経済・稼ぎ | エナジードリンク | 短時間、主人公の移動が爆速に。切れるとしばらく鈍くなる |
| 経済・稼ぎ | ピザ | 全エンジニアのペースが上がるが、技術的負債も少し溜まる |
| 経済・稼ぎ | ドキュメント | ジュニアの不正コード率がじわじわ下がる |
| 一発逆転・ネタ | 金曜日の夕方デプロイ | 売上が一気に入るが、高確率で週末に大障害 |
| 一発逆転・ネタ | ロールバックボタン | 直前の障害の損害を取り消す。1回限り |
| 一発逆転・ネタ | 「動いてるからヨシ！」 | 一定時間、不正コードを見逃す代わりにリリース速度が倍 |
| 一発逆転・ネタ | 伝説のシニアの書き置き | 周辺だけ障害が起きない。でも中身は誰も読めない |
| 一発逆転・ネタ | 猫 | キーボードを歩いてランダムなコードを1つ消す。不正かどうかは運次第 |
